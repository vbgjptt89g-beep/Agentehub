# Pruebas

Ejecuta `npm test` con Node.js 20 o posterior para comprobar la configuración y los errores del flujo OAuth, además del sellado, manipulación y expiración de sesiones. Ejecuta `npm run check` para validar sintaxis JavaScript y JSON.

Las pruebas actuales no cubren llamadas reales a GitHub, acceso a PostgreSQL, autorización por usuario en todas las rutas ni la futura ejecución aislada del worker.
